# Platform icon sources

Current UI icons prefer local SVG assets instead of favicon `.ico` files, because favicon resources are usually 16×16 or 32×32 and become blurry in the landing-page display.

## SVG assets

Most SVG assets are local copies of high-resolution vector brand icons from Simple Icons CDN:

- bilibili.svg — https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/bilibili.svg
- kuaishou.svg — https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/kuaishou.svg
- xiaohongshu.svg — https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/xiaohongshu.svg
- weibo.svg — https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/sinaweibo.svg
- channels.svg — https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/wechat.svg
- youtube.svg — https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/youtube.svg
- tiktok.svg / tiktok-color.svg — https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/tiktok.svg
- x.svg — https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/x.svg

Douyin uses the distinct Douyin Chinese wordmark SVG from Wikipedia/upload.wikimedia.org, so it does not visually duplicate the TikTok music-note icon.

Brand assets belong to their respective owners. They are bundled here only for local UI identification.
