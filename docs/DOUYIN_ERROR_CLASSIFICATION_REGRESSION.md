# 抖音解析失败分类与真实验收（2026-10-09）

输入：用户分享短链 `https://v.douyin.com/YWvLR_gHpHg/`，标题关键字“年少不知微喇好”。

## 问题与修改

- 原分享页提取失败、浏览器未捕获媒体和未配置 Cookie 会聚合成 RuntimeError。
- 分类器将任何 `cookie` 或笼统“登录态”字样判为 authentication_required，导致无登录证据也提示授权。
- 移除上述宽泛匹配，保留明确登录/认证错误及独立的授权过期分类。
- 抖音聚合失败现在使用 MediaProbeError，保留 share-page、no-login、auth-fallback 三阶段原因。
- 浏览器明确出现登录/验证等阻断时仍直接停止，不反复换策略；阶段原因通过现有脱敏函数输出。
- 对播放器初始化迟缓，只在当前页面尚未捕获任何详情或媒体时追加最多 6 秒事件等待，不访问 Cookie、不无限重试。
- 页面运行日志显示失败阶段、脱敏原因及 traceId，更新脚本版本参数避免旧缓存。

- 内置浏览器初次遇到并发容量限制，页面明确显示 probe_queue 和诊断编号，而非登录错误；容量释放后手动重试成功。未提高并发上限。
- 内置浏览器成功显示对应封面、10 路视频流和画质选项，证据：`report_figures/ywvlr-fixed-iab.png`。
